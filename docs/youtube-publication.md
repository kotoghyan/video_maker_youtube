# Утверждённая публикация через YouTube API

Команда `youtube-upload --package <absolute path> --approval <absolute path>` выполняет dry-run: сверяет SHA-256 пакета, видео, текстов, обложки, канал OAuth и все названия в uploads playlist. С HTTP GET получает существующие материалы; медиа не отправляет.

Флаг `--execute` запускает только уже утверждённый пакет. Утверждение включает хеш точного JSON-пакета, число материалов, ID канала, права, видимость и решение владельца об аудитории. Для текущего пакета 353 утверждены 13 видео, `privacyStatus=public`, `selfDeclaredMadeForKids=false`. Изменение пакета или файлов останавливает отправку. Никаких сторонних библиотек не установлено.

Загрузки идут последовательно через resumable YouTube API. Размер блока — 8 MiB. URI сессии является чувствительными данными: хранится только в отдельном DPAPI-файле вне OneDrive. После ошибки связи программа сначала спрашивает состояние прежней сессии, затем продолжает по Range; новую сессию автоматически не создаёт. Параллельные подключения/публикации заблокированы одним Windows lock. Неопределённый ответ при создании сессии требует диагностики; автоматического повторного POST нет.

После завершения загрузки video ID сохраняется до следующего API-запроса. Затем в рамках первоначальной отправки ставится утверждённая оригинальная миниатюра и через videos.list проверяются канал, заголовок, описание, реальная видимость, аудитория, uploadStatus и processingStatus. Последующие запуски пропускают уже загруженные материалы; повторной вставки, редактирования или удаления нет. Ошибку миниатюры фиксируют отдельно от видео.

Отдельный результат каждого материала записывается в `youtube-publication-results-v1.json` и журнал Museum ID. Реальные параметры, ссылки и ID не подменяются запрошенными. Несоответствие Public или аудитории, отказ/снятие загрузки останавливают отправку остальных материалов. Статус uploaded не означает окончания обработки видео YouTube; окончательная проверка выполняется после передачи пакета.

Тесты перед реальной отправкой: 85 тестов прошли. Проверены запрет неофициальных endpoint и редактирования/удаления, невывод секретов в API-ошибках, непрерывный Range, возобновление завершённой сессии без повторного POST, остановка при неопределённой инициации, корректные Public/not-made-for-kids, восстановление после обрыва, смена канала, дубли, фактический Private и аннулирование утверждения при изменении файлов.

Источники: [Resumable Uploads](https://developers.google.com/youtube/v3/guides/using_resumable_upload_protocol), [videos.insert](https://developers.google.com/youtube/v3/docs/videos/insert), [thumbnails.set](https://developers.google.com/youtube/v3/docs/thumbnails/set), [videos.list](https://developers.google.com/youtube/v3/docs/videos/list).
