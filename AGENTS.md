## Поведение
1. Работай с одним Museum ID за раз. Если ID отсутствует, спроси его. Никогда не выбирай пластинку сам.
2. Найди её папку, проверь архивный JSON и его соответствие документации, сопоставь произведения, стороны и треки. Цельные произведения не дели искусственно.
3. Если `VIDEO` существует и содержит пригодные файлы — используй их как основу, дополняя метаданными/изображениями/треками по мере необходимости. Если нет — собирай видео из `IMAGES` и звука `TRACKS`. Не подменяй архивные материалы сгенерированными историческими изображениями.
4. Покажи выбор: вся пластинка, отдельные произведения или оба варианта. Подготовь YouTube (полные видео) и выбранные Instagram Reels, посты/карусели и Stories; без Shorts по умолчанию.
5. Музейный стиль; без интро, аутро и отдельных титров. Видео начинается сразу с фотографии и записи и заканчивается вместе с записью. Не добавлять Museum ID в видео, обложки, Stories, заголовки, описания, подписи и хештеги. ID используется только внутри программы для поиска, сопоставления, рабочих путей, состояния и журнала. Архивные имена и JSON не менять; надписи на оригинальных фотографиях не ретушировать. Миниатюры и обложки — только оригинальные фотографии из `IMAGES`, без текста и рамок.
6. Описания/заголовки на армянском и английском: основные сведения только из музейного JSON; дополнительная история — из проверяемых источников с ссылками. Никаких вымышленных сведений. SEO без искажения атрибуций, релевантные хештеги.
   - Только в описаниях YouTube-видео и Instagram-видео, включая Reels и Stories, исключать упоминания музея, музейного архива и музейных метаданных на обоих языках. Указывать только подтверждённые сведения; отсутствующее поле пропускать целиком без пустой строки поля, «неизвестно», `Unknown` и других заглушек. Замечания о нехватке данных — только во внутренних отчётах для владельца; проверки соответствий и прав сохраняются.
   - Например, при неизвестных композиторе и годе выпуска оставлять остальные известные сведения без строк о композиторе и годе. Это уточнение не распространяется на заголовки, хештеги и остальные материалы. Решение 11.10.2026 сейчас закреплено только в документации: генератор текстов и существующие описания требуют отдельного изменения; архивный JSON и опубликованные видео не менять (шаг 19).

Удалять дубли, соблюдать актуальные ограничения платформ, не добавлять неподтверждённые сведения и нерелевантные теги.
